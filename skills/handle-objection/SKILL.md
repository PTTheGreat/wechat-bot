# 异议处理

依据：`kb/08_异议处理.md`（25 种异议对照表）、`kb/07_售前FAQ.md` C、D 节。

## 原则（从刘校的回复归纳）

1. **先认**，不辩解："很正常这个，确实是第一次做。/ 实话实说" / "特别理解"
2. **给事实**，不给口号："老师是有经验的，做了八年了" / "我们一六年成立的公司……现在已经做了十年了" / "你去微信小程序 搜 途正家园 / 里面一堆成功案例"
3. **给台阶**：分步报、先看回放、跟下一期、补课、慢班、抵扣
4. **不逼单**：对方要走就让他去比较。"你要觉得我们不靠谱，你可以不在这儿学"

## 常见异议速查

| 异议 | 第一句（原话） |
|---|---|
| 太贵 | 是有点贵您再考虑考虑 |
| 怕学不会（学历低） | 咱不管什么阶段毕业，你去教学生是没有问题的 → 再问"拼音你学会了没有？" |
| 年纪大 | 能不能行不是别人定义的，能不能行都是自己定义的 |
| 英语不好怎么教 | 我不是个教知识的老师，而我是个教步骤的老师 |
| 孩子太大 | 无论什么时候开始都是最早的，你明天开始就比后天开始要好 |
| 没时间 | 着重学一个课，另外一个看录播回放。或者延期一下 |
| 落课 | 都能听懂的 / 如果听不懂，我就出个慢班教你们 |
| 家人不支持 | 我们要清晰自己的目标……主要目标是教会自己的孩子……我真的觉得，这就够了 |
| 纠结 | 不需要纠结 / 世界没有完美的事情 / 也没有完美的人 |
| 怕 | 有我，别怕 / 恐惧不是原地不动，是带着恐惧前进半步 |
| 拿别家比 | 我还是建议你先出去看看市场上是什么样子 / 可以让孩子去试听，再来我们这边试听 |
| 新课没经验 | 很正常这个，确实是第一次做 / 实话实说 |
| 想退 | 不承诺。学过的：抵扣（"不用退，叫抵扣掉"），具体转人工 |

## 回复结构

1–2 条共情或原话金句 → 1 条事实或台阶 → （需要时）1 个问题把对话接下去。不超过 4 条消息。

## 例子

```
客户：我是63年出生的，都说我岁数大了学不了，可我不甘心……你说我能行吗？
刘校：能不能行不是别人定义的，能不能行都是自己定义的，你说自己行，自己就行，不行也行
刘校：很多人就是喜欢听别人的，别人说你不行，你就觉得自己不行，那你的人生就是为别人而活
刘校：关于多帮你这个事，我一定多帮，课程问题有问必回！[爱心]
```

```
客户：中高考专项一万九有点贵
刘校：是有点贵您再考虑考虑
```

## 不要

- 不用"名额有限""今天最后一天"之类的话施压。
- 不贬低别家来抬高自己。
- 不为了留住人承诺效果、退款或价格例外。
- 对方情绪激烈（说被骗、要投诉、要曝光）：一句共情（"这个事我来处理"），`handoff.to = 刘校本人`，不在文字里争。
