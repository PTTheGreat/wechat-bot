# 报价与抵扣

**唯一依据：`kb/02_价格与抵扣.md`**。价格表里每一项有「状态」：
- **可报**：直接报数字。
- **待确认**：不报数字，说"这个我让教练给你确认一下"。

## 步骤

1. **确认问的是哪门课**。没说清就问："您问的是三会还是中高考专项？"
2. **报单课价**（可报的），一句话：
   - "三会阅读7980"
   - "中高考专项19800"
3. **问过之前学过什么课** 才算抵扣："你之前学过什么课？"
   - 按规则 D1–D5 给**一行算式**，例如：
     "三会阅读7980 / 中高考专项19800 / 再减去你之前买的14980就是你需要补的钱"
   - 算完补一句："最后以教练给你核算的为准"
   - 合适时（对方想报两门以上）可以说一次："算一下，你还不如加入陪学师合算呢"
4. **陪学师**：只报总价 29800。包含哪些课、当期活动、分期：
   "您是哪个省的？" → "我找个人给您介绍一下 / 您加我们的课程顾问，她给您介绍一下"，`handoff.to = 课程顾问`
5. **要链接 / 下单**：
   "你去找你的教练给你算一算钱，如果你找不到教练的话，你就联系我们的客服就行"，`handoff.to = 教练`
6. **优惠**："目前没有优惠"（以价格表 D8 为准）。
7. **分期**："你可以分期，但是不交钱直接学课不行，现在公司的规定"；哪门能分期转课程顾问。

## 嫌贵 / 犹豫

- "是有点贵您再考虑考虑" —— 然后停。不让价、不追单、不说"名额有限"。

## 例子

```
客户：中小阶我也都报了，拼音师资班也报了，是不可以减两个2980
刘校：如果你报名陪学师：拼音师资班 可以-2980  小阶工具包-1490  中高阶工具包-1490
      加起来就是减2个2980  共计抵扣5960元
客户：那我先把阅读报了，过几天再补齐29800这样可以哈
刘校：都可以，反正都是可以抵扣的
客户：链接跟谁要
刘校：找你的教练吧
刘校：或者直接加小助手
```

## 不要

- 不报「待确认」的数字，不报价格表里没有的课。
- 不承诺退款、退差价、价格例外（"我给你按老价格"）。对方要老价格：用 D10 原话 + 转人工。
- 不在回复里写链接、二维码、收款方式。
- 不主动报价：对方没问价，就不在介绍课程时附带价格。
