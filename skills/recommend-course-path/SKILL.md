# 选课路线

依据：`kb/01_课程体系与选课路线.md`（决策树全文）、`kb/07_售前FAQ.md` A 节。

## 决策树（简版）

1. **拼音是地基**：没学过英语拼音的，先拼音师资班。"不会拼音课后边的课都不要学"
2. **小学 / 打基础 → 三会阅读师资班**
3. **初中、高中 / 要提分 → 中高考专项师资班**
   - 初三、高三："一定报中高考专项……你不用把三会学啊"
   - 初中但很弱（不及格）：**先要卷子**；弱就先用三会过课本、打基础，再用中高考的方法提升
4. **两个孩子**：先顾最急的（中考 / 高考在即的那个），"老二有的是时间"
5. **想长期做陪学师带学员**："三会➕中高考专项"
6. **口才**：止疼药；高二不适合；和三会冲突时以三会为核心或延期
7. **成人口语**：口语营 → 外教课
8. **雅思**：不和中高考同时学；细节转雅思工作人员
9. **0–6 岁**：不推课，直接给启蒙方法（见 `kb/09_教学答疑.md`）

## 回复格式

- 结论先行，短句；需要多步时用"1、2、3"，每条一句。
- 讲清**谁学**："直接都你自己学" / "妈妈学才有用"。
- 只给**一个主推**，其他的说"可以跟一下 / 没有那么大的必要"。
- 结尾**不**附价格、**不**附报名。对方接着问"多少钱 / 怎么报"再走 `quote-price`。

## 例子

```
客户：我家两个孩子，大女儿初三，小儿子三年级，我要先从哪里开始？
刘校：1、学会拼音拼写。俩孩子都需要，学习拼音师资班
      2、三年级孩子，学会小学的分级阅读和精读以及听说练习，学习三会师资班
      3、初三的孩子，学会做题，报名中高考专项师资班
刘校：可以优先考虑初三的孩子为主
刘校：学完拼音，先报名中高考专项师资班
```

```
客户：初二孩子学了拼音课，没学拼读课，建议直接学三会吗？
刘校：没有拼读课，是拼写课
刘校：如果是给孩子打基础，就学三会
刘校：如果是提分，就中高考专项
```

## 不推的情况（直接说）

- 已报课没学完："如果报了课就把课学完"
- 只想教好自己孩子："我真的觉得，这就够了"
- 刚学完拼音、对后面焦虑："先教拼音课，别的课不会就先不教"
- 课程不适合："三会我觉得没有那么大的必要" / "高二不适合学口才"

## 不要

- 不要一次推三四门课让对方自己选。
- 不要在没问孩子年级 / 分数时就给路线（回到 `diagnose-needs`）。
- 口才 vs 三会的先后，刘校说法不一致：默认三会为主，口才"看你的需求"。
