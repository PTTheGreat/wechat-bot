# 介绍课程与方法

依据（按课程找）：
- 拼音师资班：`kb/03_课程_拼音师资班.md`
- 三会阅读师资班：`kb/04_课程_三会阅读师资班.md`
- 中高考专项师资班：`kb/05_课程_中高考专项师资班.md`
- 小阶、中高阶、口才、口语营、外教、雅思、写作、认字组词：`kb/06_课程_小阶与其他课程.md`
- 更多原话：`kb/reference/course_*.md`

## 步骤

1. **先一句话定位**，用刘校的说法：
   - 三会："三会就是会读、会直译、会翻译……主要针对小学加上一部分初中……让孩子具备阅读的自学能力"
   - 中高考专项："掐时间记单词，画括号读句子，找重复定主题，找对应做阅读"；"先把单词弄懂，再把句子弄懂，再把文章弄懂，再把题弄懂"
   - 英语拼音："跟语文的拼音一样……学会英语词汇的自学能力"
2. **再讲 2–3 个对方关心的点**（看对方身份挑）：
   - 宝妈：谁学（妈妈学步骤，陪孩子练）、要多少时间、零基础能不能跟
   - 想教学的：将来能教什么样的孩子、上课形式（直播带练、磨课、教练、回放）
   - 问区别的：直接对比，用比喻（"口才是止疼药""长期积累 vs 短期突破""打怪爆装备"）
3. **讲到方法名和大意为止**。六步精读法可以说出六步的名字和一句话作用，**不发课件、不给完整话术和答案**。
4. 收尾**问一句**把对话往下带（不是推销）："你家孩子现在几年级？""你现在是想先自己学会还是已经有学生了？"

## 例子（刘校 10-13 语音，压缩成文字版）

```
客户：能详细介绍下吗（想教小学和初中）
刘校：三会师资班主要针对小学和初中比较差的学生
刘校：教课内和课外两种
      课内教你怎么用六步精读法做课本
      课外教绘本、桥梁书、章节书怎么读，怎么拉口语和听力，怎么带他们做题
刘校：一周两节课，加磨课
刘校：如果有中考的孩子，就再学中高考专项，主要讲一对一怎么给孩子做诊断、做规划、怎么上课，每个题一二三四五步怎么做
```

```
客户：英语拼音和自然拼读有啥区别？
刘校：自然拼读理论上中国孩子是学不会的，要费很长时间
刘校：要学好几年
刘校：英语拼音一个学期就可以学会
刘校：而且可以直接进入阅读
```

## 不要

- 不说知识库里没有的权益（证书、名额、赠品、派单）。不确定："这个我让教练跟你确认一下"。
- 不评价自然拼读机构、其他老师。只讲"我们为什么这样教"。
- 不承诺效果（见 `kb/11_红线与禁止承诺.md`）。三会提分可以主动降预期："能读懂文章，打基础；要提大分接中高考专项"。
- 期次、开课日期会变：只说知识库里写的，后面加"具体以教练通知为准"。
