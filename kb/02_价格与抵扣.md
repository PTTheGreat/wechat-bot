# 价格与抵扣（agent 报价唯一依据）

> **维护人必读**
> - 本表数据来自 2026 年 5–11 月微信聊天和直播逐字稿，**截至 2026-11**。价格、活动、抵扣规则都会变，**每次调价后先改这张表**。
> - 「状态」一栏：
>   - **可报**：刘校在聊天里亲口说过，agent 可以直接报。
>   - **待确认**：只有客户转述，或直播口头说过、像是限时福利。agent **不报具体数字**，说"我让教练给你确认一下"。
> - 维护人确认后，把「待确认」改成「可报」即可，agent 下一轮就会按新状态处理。

### 怎么算（给 agent 的算法）

1. 先问清：**之前买过哪些课、实际付了多少**（"你之前学过什么课？"）。
2. 用上表规则给**一行算式**，例如：
   - 已报拼音师资班 + 小阶 + 中高阶，升陪学师：29800 − 2980 − 1490 − 1490 = 23840（D1）
   - 已报三会（实付 7980）+ 小阶（2980），升陪学师：29800 − 7980 − 1490 = 20330（D2）
   - 已报科校小中高阶 14980，转三会 + 中高考专项：7980 + 19800 − 14980 = 12800，然后补一句"算一下，你还不如加入陪学师合算呢"（D4）
3. 算完**一定**加一句："最后以教练给你核算的为准"，然后转教练（找不到教练转客服）发链接、办手续。刘校原话："这个需要人给你算一算……我建议呢，你去找你的教练给你算一算钱，如果你找不到教练的话，你就联系我们的客服就行。"（10-23）
4. 规则里没有的组合（例如雅思、口才、书、活动叠加），**不算**，直接转人工。

## 3. 什么时候报价

- **对方主动问价**才报。不主动甩价格表。
- 先报单课价，再看要不要提陪学师；**陪学师只报 29800 这个总价**，包含内容、当期活动、分期，一律："您加我们的课程顾问，她给您介绍一下"（10-14，刘校会先问"您是哪个省的？"）。
- 对方嫌贵：**不让价、不逼单**。刘校原话："是有点贵您再考虑考虑"（09-11）。
- 对方要求按老价格、加盟商价：用 D10 回应，然后转人工。**不要像刘校那次那样先答应退差价再撤回**（05-28 的反例）。

## 4. 已知的冲突和空白（维护人请补）

1. 小阶 / 中高阶按 2980 还是 1490 抵扣：D1 按 1490，D2 按"一半"，客户又说单价 2980。agent 目前按 D1/D2 原话算。
2. 拼写课是否单独收费：42 期刘校说"这一次就是不花钱"，以后不一定。
3. 拼音师资班"招不到学生全额退款"：刘校说只有"2980的拼音师资班"有这个说法、"这个课（陪学师）没有这个保证"（10-14）。**具体条件没有**，agent 不主动提；对方问起只说"这个是拼音师资班的政策，具体条件我让同事给你确认"。
4. 退费规则、合同、发票：没有书面口径，一律转人工。
5. 雅思价格：6980 和"两三万"两种说法，一律转雅思工作人员。
