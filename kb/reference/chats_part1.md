### 2.1 课程选择与学习顺序

**典型提问**
- 「就想和您咨询一下我这边孩子学什么课程能够提分快？」「456年级，初中的。」（#115 09-23）
- 「后期这个课程怎么衔接？孩子们学完了拼音，接着再上怎样的？有没有一套完整的系统？」（#115 09-24）
- 「小阶课我学完了，你马上开的三会阅读我开通课程同时上，还是我学完师资班，再学三会阅读。我的单词量不太多？同时开课会不会出现跟不上情况。」（#173 09-17）

**刘校原话**
- 「小学的用三会阅读」 / 「初高中的用中高阶专项」〔"中高阶专项"疑为"中高考专项"的口误〕（#115 09-23）
- [语音]「呃，老师学完了拼音呀，就去学一下那个我们的三会阅读就可以了。啊，学一下三会阅读。啊，如果你的孩子是初高中的话，你就可以学一下中高考专项。呃，其实就学完了拼音，然后去解决小学和初高中的问题。」（#115 09-24）
- 「接下来拼音搞完」 / 「学什么」→「三会」（#115 09-29）；「那我接下来应该学什么刘校长」→「三会阅读」（#133 09-03）
- 「学完师资班再约三会」；客户问「三会是您一直带课么？」→「是我带、」（#173 09-17）
- 客户：「我现在报名了科校小中高阶那个」→「你的诉求是什么？」→（教学）→「教什么样的学生？」→（小初）→「学三会阅读师资班」 / 「如果有中高考就学 中高考专项师资班」……→ 得知已报小中高阶 →「那你就学科校的小中高就可以了」 / 「如果报了课就把课学完 / 您是想了解，其他的什么课呢？」（#151 10-13）

- 问某套雅思教材适不适合初中、高中孩子：[语音]「我觉得这个事儿最大的问题叫做你理不理解这个这套体系，你学没学明白？如果你学不明白，你的孩子也学不明白，这是第一个事儿。第二一个事儿，你的孩子是什么水平？嗯，我觉得不是所有的孩子都适合学这个，这个更适合老师自己去提升的。」（#126 08-11）

**口才 vs 三会的顺序（两处说法不一致，需人工确认）**
- 「学完拼音课之后……下一步是学三会阅读好还是口才课好呀？」→「正常是先学口才再学三会阅读」 / 「看你的需求」（#170 10-02）
- 「学了三会阅读」 / 「还要学口才课吗？」→「如果是培训师就是要学的细致一点」 / 「不是陪学师学三会就行」（#115 09-29）〔原文没有标点，含义不确定。可能是"要做培训师就学得细致些（口才也学）；不是的话，陪学师学三会就够了"〕

**回复套路**
1. 先问诉求和学生学段，再给一句话路径：**拼音 → 小学用三会阅读 / 初高中用中高考专项**。
2. 已经报了课的，先「把课学完」，不额外推课。
3. 两门课时间撞了，学一门，另一门看回放或延期（见 2.4）。
4. 回答极短，经常只有课程名（「三会」「第一期的」）。

**回复套路**：用"两条路线"（教学路线 = 三会 / 中高考专项师资班；提升自己路线 = 小中高阶）来区分课程；讲三会就讲"阅读的自学能力、六步精读、课内 + 课外"；讲拼音就讲"跟汉语拼音一样、一个学期学会、直接进阅读"，并拿自然拼读做对比。

## 6. 刘校的语言风格

### 6.1 特征（基于本文件统计）
