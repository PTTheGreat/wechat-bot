# 三会阅读师资班

> 更多原话见 `reference/course_sanhui.md`。价格见 `02_价格与抵扣.md`。

## 是什么

- 三会 = **会读（会朗读）、会直译、会翻译**。"我们基于会读会直译和会翻译……做了一个比较详细的步骤，叫做六步精读法，它是必修"（补课 10-20）
- 刘校原创："这就叫我最初当时原创的这个叫英语三会法"（答疑 10-09）
- 课内课外都能用："这个方法就是你用你套在任何一个小学或者初中的教材上去用，不管是课内和课外……都管用"（学前培训）
- 给新人讲的版本（09-03 语音）："就是……这个孩子具备阅读的自学能力的一个入门课……能让他把这些常用的核心词汇掌握住，因为会在阅读里边反复出现。另外呢，它主要针对于小学加上一部分初中，主小学副初中……给这些孩子能做规划。你比方说一二年级的孩子主要以听说为主，三四年级的孩子主要以词汇短句为主，五六年级呢要进入一些短文的阅读"
- 给想教学的人讲的版本（10-13 语音）："三会的师资班呢，就是主要是针对于小学阶段和初中呢比较差的学生……主要教课内和课外两种。课内呢，就是主要教你怎么给他们用六步精读法做课本儿；课外呢，主要教绘本、桥梁书还有章节书，那么怎么去阅读，怎么去拉口语和听力，怎么去带他们做题……一周两节课，然后加磨课。"

## 六步精读法（对外讲到名字和大意即可，不发完整课件）

一口气版："拉听力，读句子，速记词或者闪记词，直译，翻译摘串，朗读，逆向译诵基本上就背过了。"（2 期 11-20）

1. **拉听力**：无字幕动画片放两遍，"不需要你听明白你有印象即可"
2. **读句子、找陌生单词**：查词典，写音标和汉语
3. **拼音拼写速记词（闪记）**：看英文说意思，"第一个叫做找自信……第二个……看到英语单词，知道它的汉语意思"
4. **直译、摘串、翻译**："直译是英语思维的汉语化"；"你不会断句，你就不会摘串，你不会摘串，你就不会阅读"
5. **练朗读**：有字幕动画片跟读，外教领读，"有样学样"
6. **逆向译诵**：看着直译说出英文，再遮住说翻译，"中英思维对切"
- 选修：讲故事（汉语 → 汉堡包中英夹杂 → 全英复述）、做真题。"能力强的孩子把选修一块给我干了，能力一般的孩子……干六步就可以"

## 适合谁

- 学员：零基础、年纪大的都有。"你们有小学毕业的，有初中毕业的……甚至有还有大学老师"；"零基础能参加，可以跟得上"（直播 11-06）
- 前置：学完英语拼音。"学完拼音课，直接教三会阅读"（10-24）
- 将来教的孩子：小学 1–6 年级为主，加初中基础弱（"在初中连及格都不及格的"）；没做过英语启蒙、当外语学的孩子。

## 上课形式（会变）

- **刘校亲自带**（"三会是我教"），腾讯会议直播 + 回放（切小段 + 完整版）
- 小组磨课（3 人起），轮流当老师 / 学生 / 观察者；有教练陪
- 材料：瞧这一家子（100 本，每本配题）、西游记教学版、象人（书虫 1 级），都配有/无字幕动画；课内按当地教材版本做课本动画（人教 / 外研 / 译林 / 沪教等，3–6 年级）；途正闪记小程序；PPT 课件
- 2 期加了讲师团和外教配合朗读
- 期次：1 期 2026-09-17 开营；2 期 2026-11-18 开营。下一期时间问教练。
- 晚报名可以补课："我下周给新学员补两节课"；"如果听不懂，我就出个慢班教你们"（10-13/16）

## 能说的结果

- "我要求在座的每一位人……你到最后都能把象人这本小说，用我们汉语的方式，把它翻译出来"
- 三会是长期积累：打阅读基础、具备阅读的自学能力。
- 关于提分，刘校自己的说法（可以用来**降预期**）："我们三会能不能教人家提分，肯定是能教人家提分，能不能提大分……提不了……你可以让他读懂文章，但是你没有教他做题技巧"；"如果这个孩子现在只有五六十分，你用三会的方式给他打打基础……应该能考个七八十分……但你再往上提这个事儿就提不了"。要提大分接中高考专项。

## 和别的课的关系

- 三会 → 中高考专项："你再往上提，可能有很多的做题技巧……也就是后面我们的中高考专项"；"你们现在学的这个东西叫长期积累……学中高考专项做这些题的时候叫……短期突破"
- 和口才："我讲的是阅读"；口才句型可以融进教课本
- 和小阶："如果你在上三会的话，放弃掉小阶，就是因为这个拼写我后续会在三会上给你们融进去"（直播 09-28）

## 不能说

- 提分数字、"高考不会掉下120分"之类的课堂激励话
- 收入、接单（"在我们平台上接学生教也行"——规则需人工确认）
- 报了就把全套答案、逻辑发给你（刘校："我今天绝对不会给大家，你们必须自己做一遍"）
- 点名评价别的机构 / 老师
