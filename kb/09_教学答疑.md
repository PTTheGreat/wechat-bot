# 教学答疑：先给价值，再谈课

> 售前里最能"接住"人的，是先把对方眼前的孩子问题答好。刘校的套路：**要材料 → 一句话诊断 → 开"方法处方"（落到课程里的方法）→ 引回课堂**。
> 这里每条都是刘校的真实答法。agent 可以照着答，但不要把整套步骤课件发出去。

## 1. 先要材料

- "你把孩子的完成句子的这个题的原题拍照给我看 / 我只看答题卡没法做判断"（#232）
- "孩子7年级，考62分，满分是多少呀？"（#187）
- "就是你现在是怎么教的孩子？"（#115）；"你之前是怎么试课的？如何失败的？孩子如何反馈"（#165）
- "我需要知道具体是怎么不配合的"（#165）
- 对方发了图片（试卷、作业）：agent 看不到图片时，说"图我这边打不开，你把题目和孩子的答案打字发我一下"，或转刘校本人。

| 7 年级阅读理解扣分多 | "用三会大阅读师资班的方法，先帮孩子过一下英语课本，掌握好课内的内容 / 然后带着孩子阅读课外的书籍，我们的象人书籍用起来 / 主要还是提升词汇量和阅读理解的能力"（#232） |
| 9 年级快中考 | "直接用你们省的中考真题 / 用三会大阅读师资班的方法过 / 过10套左右的中考真题 / 然后用一下中高考师资班里面的方法"（#280） |
| 六年级 65 分，注意力差、一听就忘 | "分2步 / 1.用六步精读法给他过课本 / 2.用音型意结合的方式记单词"（#276） |

| 20 分的孩子直接啃课本 | "20分的孩子，这个文章对孩子来说太难了 / 你降低文章的难度系数哈，否则对一个20分的孩子来说，会有很大的畏难情绪的"（#165） |

| 情态动词怎么讲 | "情态动词 就是帮忙的 和动词一起表示动作 / 例如 / you can go 这里面的动词就是 can go"（#206） |

| 一周只能上一次课 | "稍微布置点作业，周一到周五让他稍微复习一下……正常来讲就是周六排一次课，一次课一个半小时，分为两个小节课，四十五分钟一节课，然后中间休息十分钟"（#115） |

## 3. 孩子不愿学（课上答疑的共识，编辑摘要，非原话）

- 先看孩子在你这儿是什么感受；夸要夸具体细节，不拍马屁。
- 把练习拆成孩子能完成的小步，完成就马上肯定。
- 孩子有情绪，先跟后带，先理解感受再处理学习。
- 材料太难就降难度，找到能开始的位置再往上走，不按年级硬推。

## 4. 答完以后

- 引回课堂而不是推销："我下节课演示一下"（#165）；"三会阅读就会教"（#115）；"你如果是三会阅读的学员，你周五晚上跟一次我的拼写课的直播"（#135）
- 对方还不是学员：答完问题后，**最多一句**点到对应的课（"这个在三会里我是一步步带着练的"），对方追问再展开。
