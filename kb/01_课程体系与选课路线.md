# 课程体系与选课路线

## 1. 一句话讲清体系（对外可直接说）

刘校原话（09-03 语音，整理）：
> 我们这个是一个新的体系，这个新的体系的第一步就是要学英语拼音，因为它完全跟汉语是一样的。我们为什么要学拼音？是因为我要让孩子具备词汇的自学能力……他读了我们带拼音的课外阅读书，才能认识大量的词汇量，慢慢的把拼音甩掉……能读懂这些书，他能积累很多很多的这种常用的、核心的阅读词汇量。那么有了这些东西，他再去做题，他起码就能读懂题。他读懂题以后，我们再教他英语的一些做题的技巧，那么他就能够很快速的去提分儿，所以这是一个过程。

短版：**拼音（单词会读）→ 拼写（单词会写）→ 三会阅读（文章读懂，打基础）→ 中高考专项（做题提分）**。
刘校："拼音拼写……三会阅读，中高考专项，这四个大课你学明白了就非常可以了"（2 期开营 11-18）；"我觉得这三个东西是我这十几年研究的王牌"（直播 11-09）。

## 2. 两条路线（先分清对方要哪条）

刘校原话（10-13 语音）：
> 我们加盟的没有加盟这个业务，就是我们叫陪学师……我们这个陪学师呢有两条路线，一条是教学的路线，一条是提升自己的路线。你买的这个呢叫小中高阶是提升自己的路线，然后我们教学那个呢就是三会阅读中高考的那些师资班。

| 路线 | 课程 | 适合 |
|---|---|---|
| 提升自己 | 小阶工具包、中高阶工具包、科校小中高阶、口才、成人口语营、外教课 | 想自己把英语捡起来、成人口语 |
| 教学（陪孩子 / 教学生） | 拼音师资班 → 三会阅读师资班 → 中高考专项师资班；陪学师（全体系） | 教自己孩子、做陪学师接学生 |

- 有人问"加盟"：先纠正——"没有加盟啊 / 只有陪学师"（10-13）。
- 三种目标要分开问（编辑摘要，非原话）："先分清是自己提升、陪孩子学，还是准备教学生，再安排学习。"

## 3. 选课决策树（按刘校实际回复整理）

先确认三件事：**给谁学（自己 / 孩子 / 学生）**、**孩子几年级、考多少分（满分多少）**、**之前学过什么课**。

### 3.1 地基：拼音
- "各位我们体系里边拼音课是打底的，不会拼音课后边的课都不要学"（11-20）
- "学完拼音就可以学习三会了"（09-11）
- 没学过拼音的大孩子也先回炉："那我觉得你先把拼音课教给他吧！"（五年级，09-28）
- 有拼读课吗？"没有拼读课，是拼写课"（09-11）

### 3.2 小学 / 打基础 → 三会阅读
- "小学的用三会阅读"（09-23）
- "如果是给孩子打基础，就学三会 / 如果是提分，就中高考专项"（09-11）
- 三年级："学会小学的分级阅读和精读以及听说练习，学习三会师资班"（09-11）

### 3.3 初中、高中 / 要提分 → 中高考专项
- "初高中的用中高考专项"（09-23）
- 初三、高三："如果你的孩子是初三了啊，你一定报中高考专项啊……这个事儿我觉得是毋庸置疑的……你不用把三会学啊，你直接学中高考专项去教你儿子就可以"（10-22）
- 初一、正常能及格："还是从中高考专项开始。嗯，三会我觉得没有那么大的必要"（10-22）
- 初一 132 分："家长我的建议是学中高考专项"（10-16）

### 3.4 例外：初中但基础很弱
- 看了 62/120 的卷子后改口："孩子算是英语基础薄弱的……建议你按照选择三会大阅读课程的学习方法，帮她过课本，过课外的阅读，过课后的习题，帮孩子把基础打好哈 / 基础打好之后，你用中高考的方法，帮她做提升"（10-24）
- 中高考课上："先从三会开始，如果他很弱的话；如果他孩子高三了或者什么的，这些可能学中高考专项更利于他"（10-27）
- **结论：先要卷子再定**。"你把孩子的……原题拍照给我看 / 我只看答题卡没法做判断"（10-16）

### 3.5 两个孩子
- 先顾最急的："可以优先考虑初三的孩子为主 / 学完拼音，先报名中高考专项师资班"；"这半年先把老大弄好 / 老二有的是时间"（09-11）
- 老大大学、老二 9 岁："中高考专项可以帮助老大，三会能帮助老二"（10-09）

### 3.6 想长期做陪学师带学员
- "我的建议是你学三会➕中高考专项 / 这个会一直可以带学员"（08-27）
- 手上已有多个学生："老师，我觉得你应该上三会阅读的课程"（10-22）

### 3.7 口才 / 口语
- 口才的定位："口才课还是要学，但是口才课是止疼药"（10-13）；"口才解决的是句子问题……它可以救急，但它不救穷"（拼音课）
- 高二："高二不适合学口才"（10-10）
- 口才和三会撞车："我建议你核心先学会三会阅读的六步精读法，先用起来，然后把口才的句型转化融合到教课本里面去是最好的"（10-13）；或"你把口才延期上 / 跟这一期的三会"（10-10）
- 直播总路线："拼音和拼写，接下来……你可以去学学口才，然后口才其实最后再学也可以"（11-09）
- ⚠ 口径不一致：零基础家长，一次建议"报口才……因为你基础太弱了"（孩子二年级，10-09），另一次建议"学3会，你基础弱，比较好教"（孩子一年级，09-30）。agent **默认推三会**，口才作为可选，并说明"看你的需求"。

### 3.8 成人口语
- 顺序：口语营（零级→三级，起码跟 3–4 期）→ 外教课（每周 2–3 节、25 分钟一节）。"先把你以前的词儿捡起来，就你先不要学新的"（10-22）
- 词汇量不够："可以的，边练习口语，边提升自己的词汇量。口语就得开口练习"（10-24）
- 带孩子的妈妈："你在家里说英语，也会给孩子创造英文的氛围"（10-24）

### 3.9 雅思
- "学雅思不能跟着学中高考"（08-27）
- 不为雅思需求推陪学师："不是我们没有加盟哈，就是加入陪学师体系吧……你不如直接让你女儿报个我们这边雅思"（09-30）
- 先问目标分数、城市、现有水平；雅思细节转雅思工作人员。

### 3.10 幼儿（0–6 岁）
- 不推课，直接给方法："1 5岁前少看动画片 / 2 要多听，听是最重要 / ……只要一个英语环境，每天至少3-4小时"；"坚持3-6个月"（09-12）
- 拼音师资班不建议收幼儿园大班："能不能教会也能教会，但是时间有点太长了"（拼音课）

## 4. 不推销的情况（刘校会明确劝退或劝缓）

| 情况 | 刘校原话 |
|---|---|
| 已经报了课还没学完 | "如果报了课就把课学完"（10-13） |
| 两门课时间冲突 | "着重学一个课，另外一个看录播回放。或者延期一下"（10-07） |
| 只想教好自己孩子 | "我真的觉得，这就够了"（09-07） |
| 刚学完拼音、对后面焦虑 | "我建议你就是先教拼音课，别的课不会就先不教"（09-23） |
| 课程不适合 | "三会我觉得没有那么大的必要"；"高二不适合学口才"；"学雅思不能跟着学中高考" |
| 嫌贵 | "是有点贵您再考虑考虑" |
| 对我们没信心 | "我还是建议你先出去……看看市场上是什么样子……你要觉得我们不靠谱，你可以不在这儿学"（07-05） |

## 5. 谁来学：妈妈学，陪孩子练步骤

- "直接都你自己学"（09-11）
- "孩子学是没有用的 / 妈妈学才有用"（09-23）
- 语音（09-24）："如果我们要教知识这个事儿特别特别难，我们都做不到。但是呢，如果我们要讲步骤，这个事儿就非常好……孩子可以学啊，但是呢，主要是得有个人在旁边去陪着他，然后做互动、做引导、做夸奖……妈妈能学最好，妈妈学，孩子也可以旁听一下，没关系。"
- "我不是个教知识的老师，而我是个教步骤的老师……刘翔的教练永远都没有刘翔跑得快，你也不需要比他老师水平高到哪里去。"（直播 11-06）
- "我们就是想让妈妈成为孩子的第一任英语老师"（09-07）
