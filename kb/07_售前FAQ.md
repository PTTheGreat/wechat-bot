# 售前高频问题（问法 → 刘校怎么答）

> 每条："问法"是客户真实说法；"刘校原话"逐字；"要点"是 agent 回复时必须做到的。
> 来源编号（#数字 月-日）对应 `reference/chats_part*.md`。

## A. 我该学什么 / 先学哪个

**A1 "我要先从哪里开始？"（宝妈，孩子初三 + 小学三年级）**
- 刘校原话（#217 09-11）：
  "1、学会拼音拼写。俩孩子都需要，学习拼音师资班 / 2、三年级孩子，学会小学的分级阅读和精读以及听说练习，学习三会师资班 / 3、初三的孩子，学会做题，报名中高考专项师资班" / "可以优先考虑初三的孩子为主" / "学完拼音，先报名中高考专项师资班"
- 要点：先问清孩子年级；分条给路径；两个孩子先顾最急的。

**A2 "学完拼音接下来学什么？"**
- "三会阅读"（#133 09-03）；语音："老师学完了拼音呀，就去学一下那个我们的三会阅读就可以了。如果你的孩子是初高中的话，你就可以学一下中高考专项。其实就学完了拼音，然后去解决小学和初高中的问题。"（#115 09-24）
- 要点：一句话结论，不展开。

**A3 "孩子初三，30 分左右，先学三会还是中高考专项？"**
- 语音（#248 10-22）："老师，如果你的孩子是初三了啊，你一定报中高考专项啊……这个事儿我觉得是毋庸置疑的。你看回放也能学会，就你跟你儿子一起看回放，一起做作业就可以啊。那个他就剩一年了……你不用把三会学啊，你直接学中高考专项去教你儿子就可以。"
- 要点：初三/高三直接中高考专项；没时间就看回放。

**A4 "孩子初一，三会和中高考专项选哪个？"**
- 先说："如果你家孩子平常正常的考试能及格的话，就是还是从中高考专项开始。三会我觉得没有那么大的必要。"（#187 10-22）
- 看过卷子（62/120）后改口："孩子算是英语基础薄弱的……建议你按照选择三会大阅读课程的学习方法，帮她过课本，过课外的阅读，过课后的习题，帮孩子把基础打好哈 / 基础打好之后，你用中高考的方法，帮她做提升"（#187 10-24）
- 要点：**先要分数和满分、最好要卷子**，再定。

**A5 "我想了解一下加盟"**
- "没有加盟啊 / 只有陪学师"；接着问"你的诉求是什么？" / "教什么样的学生？"（#151 10-13）
- 要点：先纠正说法，再诊断。

**A6 "我报了小中高阶，是不是报错了？"**
- 先："如果报了课就把课学完 / 您是想了解，其他的什么课呢？"；对方坚持要学教学路线："哦，那要不你就转过来吧，转过来正好跟着这一期上呗。"→"是可以抵扣的"→给算式（#151 10-13）
- 要点：先劝学完；对方坚持才谈转课和抵扣（`02_价格与抵扣.md` D4）。

**A7 "三会和口才一起学跟得上吗？"（白天上班）**
- "着重学一个课，另外一个看录播回放。/ 或者延期一下。" / "哪一个最想学，就先学哪个，另外一个延期到下一期学习"（#135 10-07）

**A8 "孩子高二，要不要上口才？"**
- "高二不适合学口才"（#319 10-10）

**A9 "这个课是家长学还是孩子学？"**
- "直接都你自己学"（#217）；"孩子学是没有用的 / 妈妈学才有用"（#264 09-23）
- 语音（#264 09-24）："妈妈能学最好，妈妈学，孩子也可以旁听一下，没关系。然后让孩子看回放什么都没关系。但是呢，最重要的是……这个妈妈有时间，并且有毅力、有决心……把步骤练到位……因为咱又不是以知识性为主的，咱主要是以步骤，然后让孩子养成习惯，然后以及调整孩子的状态为主。"

**A10 "雅思和中高考能一起学吗？"**
- "学雅思不能跟着学中高考" / "主要是看你自己想要什么 / 不需要纠结 / 世界没有完美的事情 / 也没有完美的人"（#265 08-27）

## B. 课程是什么 / 有什么区别

**B1 "三会阅读是讲什么的？"** → 见 `04_课程_三会阅读师资班.md`"是什么"，用 10-13 那段语音的口径。
**B2 "中高考专项是讲什么的？"** → 见 `05_课程_中高考专项师资班.md`，用 09-11、10-13 语音口径。
**B3 "英语拼音和自然拼读有什么区别？"**
- "自然拼读理论上中国孩子是学不会的，要费很长时间。/ 要学好几年 / 英语拼音一个学期就可以学会 / 而且可以直接进入阅读"（#130 09-11）
**B4 "阿丽老师的拼写课和认字组词是一个东西吗？"**
- "阿丽老师的拼写课主要是通过一些归纳的小'规则'让孩子去练习拼写。我的认字组词是通过音型对应和型音对应去在阅读中自己多见多练。如果你通过阿丽的课已经拿到了结果，就在阿丽老师的课基础上迭代优化就行"（#135 10-23）
**B5 "有了六步精读法，是不是可以不学口才？"**
- "口才课还是要学，但是口才课是止疼药"（#206 10-13）
**B6 "这一期和下一期有什么区别？"**
- "第一期投入的精力和资源会更多" / "我也不知道能差多少" / "主要是答疑多吧"（#180）；"下一期也是我带，你跟下一期没问题"
**B7 "你们是不是就教课本、教题？资质有问题吗？"**
- 能说："我们的师资班都是有英语游戏盒子的不是纯教题，学课本 / 我们更像阅读馆"；"主要教自己孩子，次要教别人孩子赚钱，是我们的主线"（#173 09-12）
- **合规结论不由 agent 下**，见 `11_红线与禁止承诺.md`。
**B8 "成人口语课、外教课是什么？"** → `06_课程_小阶与其他课程.md`。

## C. 我能不能学会 / 来不来得及

**C1 "我初中学历，零经验，能学会吗？能招生吗？"**
- 语音（#133 09-03）："咱不管什么什么那个阶段毕业，你去教学生是没有问题的……你感觉拼音你学会了没有？……如果有了这个前提，我再跟你进行下一步的指导。"
- 文字："有我，别怕 / 你去微信小程序 搜 途正家园 / 里面一堆成功案例 / 恐惧不是原地不动，是带着恐惧前进半步 / 你一定行 / 要逼自己一把"
- 要点：学历不是问题，前提是步骤学会没有；给情绪支持 + 让对方自己去看案例。

**C2 "我 60 多岁了，能行吗？"**
- "能不能行不是别人定义的，能不能行都是自己定义的，你说自己行，自己就行，不行也行，很多人就是喜欢听别人的，别人说你不行，你就觉得自己不行，那你的人生就是为别人而活。" / "关于多帮你这个事，我一定多帮，课程问题有问必回！" / [爱心]（#330 09-30）

**C3 "我英语不好，能教孩子吗？"**
- "我不是个教知识的老师，而我是个教步骤的老师……刘翔的教练永远都没有刘翔跑得快，你也不需要比他老师水平高到哪里去。"（直播 11-06）
- "他妈妈不一定懂很多的英语知识，但是懂如何训练这个孩子做步骤，步骤里边不标准动作有没有做到位，这个就是最关键的。"（#238 09-11）

**C4 "孩子高三了，现在家长学还来得及吗？"**
- "这个太能了"（#264 09-23）；"无论什么时候开始都是最早的，嗯，就是你明天开始就比后天开始要好……这个不用焦虑，这个是事实"；"所以这个事儿呢，就是肯定是来得及。"（09-24）
- 要点：说"来得及"，**不说能提多少分**。

**C5 "落了几节课，能跟上吗？"**
- "都能听懂的" / "如果听不懂，我就出个慢班教你们"（#180 10-16）；"你现在报名就跟着课就行了，然后正好我们现在进入一个新的阶段，你前面不听，你后边也能跟得上"（#115 10-22）
- 补课、进群转小助手。

**C6 "我三班倒，没时间磨课"**
- "老师，你这个情况，我建议你跟下一期吧，这一期因为加了许多新学员，有许多补课，相对较累，另外你这一期也可以先看回放，提前学习。"（#187 10-21）

**C7 "我是不是得全部学完再去招生？"**
- 语音（#133 09-03）："你一定不要有一个心态，就是我必须把这个事儿……全都学会了，我再去教孩子，不是的"；"你先收第一个学生，你免费教都行"

## D. 家人 / 目标

**D1 "家人不支持我做副业，我这课该怎么学？"**
- 刘校原话（#173 09-07）：
  "我觉得是这样，我们要清晰自己的目标 / 我觉得你的主要目标是教会自己的孩子，你的次要目标是享受语言带给你的兴趣和乐趣。/ 我真的觉得，这就够了。/ 我们做这个陪学师，不是为了让大家去赚多少钱，而是你先学会，陪着自己的孩子学好，不报班学习会省钱。/ 另外，给自己准备一个备份副业，如果有一天，你也可以通过这个事情赚钱，而不是一定要去赚钱。"
  "你自己来学，带好孩子，就是杨妈和我做这个事情的初衷，我们就是想让妈妈成为孩子的第一任英语老师[呲牙]"
- 要点：不推副业、不推加课。

**D2 "家里意见大，以后学一个报一个"**
- "特别理解" / "没问题"（#255 05-13）

## F. 招生 / 收费（已是学员问）

**F3 "家长说没提分，我怎么安慰家长？"**
- "为啥要对付家长？"；语音："我觉得你不用安慰哈，你只要回复就可以了。我觉得从一开始呢，我们需要给家长做一个英语学习规划……第一部分呢，我们要教会他拼音和拼写，那大概是十六次到二十次课程……第二……每周学三会……大概也得是二十次课左右……提分的时候，必须是学到三会的时候才可以提分"（#115 10-16）
**F4 "能跟家长保证一学期教会吗？"** → "有可能，但是你就别去保证了，你可以说学不会免费教"（#170 09-11）
