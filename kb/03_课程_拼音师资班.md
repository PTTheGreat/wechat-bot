# 拼音师资班（英语拼音 + 拼写）

> 更多原话见 `reference/course_pinyin.md`。价格见 `02_价格与抵扣.md`。

## 是什么

- "咱们拼音课能学会什么？叫做学会英语词汇的自学能力，学会只要有音标，就能读单词……主要是我们这个事能让孩子去自主阅读"（入学测试课）
- "拼音它就跟语文的拼音一样，是我们能把这种语言的文字符号能发出声音来的一个标准"（拼写1）
- "英语里边？韵母等于叫元音。声母就等于叫辅音……整体认读音节等于叫成音节"（元音课）
- 音标 48 个扩充到 73 个："我们是学的是73个音标的拼读法"（元音课）
- 核心方法：**五步成音法**。拼写部分：**简单单词套公式，复杂单词对音标**（音形对应），最后回到文章里"音形意结合"。

## 和自然拼读、音标有什么不一样（最常被问）

- "英语拼音更适合中国孩子学拼读……自然拼读，英语为母语国家的人去学的，才有自然环境，我们没有自然环境"（入学测试课）
- 聊天里的短版："自然拼读理论上中国孩子是学不会的，要费很长时间。/ 要学好几年 / 英语拼音一个学期就可以学会 / 而且可以直接进入阅读"（09-11）
- 不是全盘否定："我们把自然拼读里边优势的东西拿了进来，我们把音标里边优势的东西拿了进来，二者一结合，变成了适合我们中国人去学习的东西"（带读课）
- 不纠结发音："不要陷入纠音的怪圈发音的怪圈"（元音课）
- 刘校教学员什么时候跟家长讲这个："如果家长问你……你就跟他说说。如果家长不问你，你就不用说"（09-12）

## 适合谁

- 学员：零基础成人、宝妈都有。"咱不管什么什么那个阶段毕业，你去教学生是没有问题的"（09-03）。"你读的不准也没有关系，因为所有人在中国学音标学的都是不准的"（元音课）
- 将来教的孩子：上了小学的孩子，九年义务教育阶段；初中、高中单独教。"小学的放一起，初中的单独教"（09-28）
- 不建议收幼儿园大班（时间太长）。

## 上课形式（会变）

- 刘校直播带练："上直播课，我带着你们练"；跟小阶的区别："在课上，咱有充足的时间，我带你们一点儿去练，而在小阶我是没有时间带你们去练的"（带读课）
- 回放在小鹅通；磨课教练 + 小组磨课；要求写逐字稿去磨课。
- 42 期顺序：入学测试 → 元音 → 辅音 → 音节与成音节 → 五步成音 → 音调 → 特殊音 → 带读拼读 → 结营招生 → 拼写 1–4 → 福利课。

## 孩子多久能学会（能说的版本）

- "真实的是 拼音16-20节课 拼写16-20节课 每节课1.5小时"（09-23）
- "英语拼音这种学得快的孩子，10节课就学完了"（课上），"一个学期就能学会"。
- 对外说"一般 16–20 节，看孩子"，**不保证**。

## 学完能干什么

- 先教拼音、收第一个学生："如果你觉得你拼音学会了，你必须去招拼音的学生……你先收第一个学生，你免费教都行"（09-03）
- 拼音阶段的目标是信心，不是提分："不要想着在学拼音和拼写的时候去给孩子提成绩 / 这个阶段应该给孩子提升信心，就是他能拼读单词的信心和能记住单词的信心"；"千万不要在这个阶段说要给孩子提成绩"（09-28）
- 跟家长讲规划：拼音拼写约 16–20 次课，之后三会约 20 次，"提分的时候，必须是学到三会的时候才可以提分"（10-16）

## 招生方法（刘校教学员的，也是他自己的售前顺序）

1. 寒暄，问分数、年级、哪儿不会；讲英语学习认知（"阅读里遇到陌生词读不出来，所以要学拼音"）
2. 学习力测试（交钱前做，最好见面、家长在场）：发音与注音、舒尔特方格（视听注意力）、自学能力（读很难的词）
3. 公开课 / 体验课：英汉学习顺序 + 一对多互动，用 10–20 个单音节词当场带拼（"让他们觉得哎呀，通过这个事他学会了"）
4. 报名；不报就"微信追他就行了"（09-12）
- 免费试听转收费（编辑摘要）："先让孩子做出一点看得见的成果，再和家长谈后续……别只讲一个价格。"
- 拼音和拼写要不要捆绑："如果家长的问题是解决孩子单词的问题，那你可以说拼音拼写一起报 / 如果家长的诉求不是写单词 / 那就不必这么捆绑"（09-23）

## 不能说

- "永远不忘"、"听音会写见词会读"（刘校："谁要是说……能让你们听音能写看字会读，这就是个骗子"）
- 发音能教得像外国人；孩子有阅读困难症（不做诊断）
- 收入数字（"一个暑假就能收六七十万"是刘校举的别人的例子，不能当承诺）
- "招不到学生全额退"：只在对方问起时说"这是拼音师资班的政策，具体条件我让同事给你确认"
